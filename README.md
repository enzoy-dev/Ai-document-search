# AI Document Search

Semantic document search API built with **RAG** (Retrieval-Augmented Generation).

Upload PDF documents, and the system will index their content. You can then ask natural language questions and get answers generated by Gemini based only on the indexed documents.

## Features

- PDF upload with validation
- Text extraction and chunking
- Embeddings generation using `all-MiniLM-L6-v2`
- Persistent vector storage with FAISS
- Semantic search + answer generation with Gemini
- List and delete indexed documents
- Relevance filtering to avoid hallucinated answers

## Tech Stack

- **Python**
- **FastAPI**
- **sentence-transformers** (embeddings)
- **FAISS** (vector search)
- **Google Gemini** (answer generation)
- **pypdf** (PDF text extraction)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/enzoy-dev/Ai-document-search.git
cd Ai-document-search
2. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate   # Linux/Mac
# or
.venv\Scripts\activate      # Windows
3. Install dependencies
pip install -r requirements.txt
4. Set up environment variables
Create a .env file in the root directory:
GEMINI_API_KEY=your_api_key_here
Get your API key from Google AI Studio.
5. Run the API
uvicorn app.main:app --reload
Interactive documentation available at:
http://localhost:8000/docs
